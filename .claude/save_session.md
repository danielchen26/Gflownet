# Quick Session Commands

## To Save Current Session

Ask Claude:
```
"Please save our conversation summary to .claude/sessions/"
```

## To Load Previous Session

Ask Claude:
```
"Please load the previous session context from .claude/sessions/"
```

## To See Session History

Ask Claude:
```
"Show me recent session logs"
```

## Automatic Context

When you open this repository in Claude, you can simply say:
```
"Continue from where we left off"
```

And Claude will check the session logs to restore context.
