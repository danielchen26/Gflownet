# GFlowNet Examples

This directory contains example implementations demonstrating various applications of GFlowNets in different domains.

## Available Examples

### [Grid World](grid_world/)
A simple grid world navigation example that serves as a basic introduction to GFlowNets. It demonstrates state and action representations for 2D grid environments.

### [Molecular Design](molecule_design/)
An example showing how GFlowNets can be used for molecular design. It demonstrates a composition-based approach for defining domain-specific types and implements molecule construction through sequential actions.

### [Causal Discovery](causal_discovery/)
This example demonstrates how GFlowNets can be used for causal discovery, finding directed acyclic graphs (DAGs) that best explain observed data.

### [Active Learning](active_learning/)
An example showing how GFlowNets can be used for experimental design and selecting informative experiments.

## Setting Up Examples

Each example has its own isolated environment with a separate `Project.toml` file. This ensures that examples have only the dependencies they need and can be run independently.

To set up all example environments at once, run:

```julia
julia examples/setup_examples.jl
```

This script will:
1. Link the local GFlowNet package to each example as a development dependency
2. Install all necessary dependencies for each example

## Running the Examples

After running the setup script, each example should be run from its own directory:

```bash
cd examples/grid_world
julia grid_world.jl
```

This ensures that the example uses its own project environment with the correct dependencies.

## Example Structure

Each example directory contains:
- The main example script (e.g., `grid_world.jl`)
- A `Project.toml` file with example-specific dependencies
- A README with details about the example
- Output files generated by the example (when run)

## Creating New Examples

When creating new examples, please follow this structure:
1. Create a new directory under `examples/`
2. Create a `Project.toml` file with necessary dependencies (excluding GFlowNet, which will be added as a development dependency)
3. Write your example scripts
4. Run the setup script to link the GFlowNet package
5. Include a README explaining the purpose and functionality

Do not include a direct dependency on GFlowNet in your Project.toml file, as it will be added as a development dependency by the setup script.
